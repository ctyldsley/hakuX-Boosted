# hakuX-Boosted

Read `boosted/HANDOFF.md` before doing anything: it holds the current state,
what is waiting on whom, the findings so far and the rules for working in
this repository. Update its "Right now" section and its session log before
a session ends, and commit it with the work.

Work on the branch `claude/xbox360-emulator-architecture-eac8l7` unless told
otherwise. The app is built by GitHub Actions on every push
(`.github/workflows/boosted.yml`); a cloud session cannot build it locally.

`HANDOFF.md` at the repository root is upstream hakuX's own and is about its
author's machine and devices, not this fork.
