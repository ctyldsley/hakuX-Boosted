# hakuX-Boosted: the translator settings the instruction tests run with.
#
#   label ; suites (a regular expression over file names, . for all) ; flags
#
# Every line is run after the reference (all defaults) and compared with it.
# "." runs all 142 thousand tests (about nine minutes a line on GitHub's
# runner); the narrower expressions keep the job's length down. Six lines
# run everything: the two stress lines of wide pinning, the ABI level of the
# dead store pass, everything together at both page sizes, and the frame
# chain. Every line was run over all the tests at least once in the
# session that wrote it (boosted/notes/translator-wide.md). The seq_
# suites (loops, calls, flags over blocks) run with every line.
#
# Markers at the end of the flags:
#   #ignore=flags   leave the full flags hash out of the comparison
#   #16k            run under qemu with 16 KiB pages (the phone's page size),
#                   in processes of at most 1,500 tests each: a long-lived
#                   process under qemu at that page size aborts in glibc's
#                   allocator, with every setting off as well (see the
#                   notes)
#

# Wide pinning (this branch). The cost model declines to pin a register
# that is busy round calls, so on their own these lines exercise few
# write-backs and reloads; the stress lines pin the most used registers of
# every function regardless, which exercises all of them. The verify lines
# keep the context authoritative and compare every pinned register with it
# at each read (they catch a missing reload; a missing write-back is caught
# by the lines without verify).
